2. INSTALLATION & SETUP (How to run locally)
--------------------------------------------------------------------------------
[PREREQUISITES]
- Python 3.10+ installed.
- Google Chrome browser.

[BACKEND SETUP]
1. Navigate to `backend/` folder.
2. Activate Virtual Environment (if not active):
   Windows: `.\venv\Scripts\activate`
3. Install Dependencies:
   `pip install -r requirements.txt` (Note: `mediapipe` and `torch` are large).
4. Start Server:
   `python app.py` (Or use the `start_server.bat` script in root).
   *Server runs on localhost:5000*

[EXTENSION SETUP]
1. Open Chrome and go to `chrome://extensions`.
2. Enable "Developer mode" (top right).
3. Click "Load unpacked".
4. Select the `extension/` folder from this project.
5. Pin the "Veri-View" icon to your toolbar.

[BACKEND] `d:/Codes/Veri-View/backend/`
